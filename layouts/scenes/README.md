# Scene layouts

The artist's compositions, kept as drawn. When writing a panel, look here
first for a layout of the same kind; name it in the panel's `layout` field
(e.g. `"layout": "scenes/0.5-forest"`). Rules drawn from them:
`docs/design/composition.md`. Props extracted from them: `data/props/`.

Add a layout: save it here as `<size>-<subject>.svg`, add a row below,
extract any new props, and add what it teaches to the composition notes.
