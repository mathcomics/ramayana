# Contributing

Thank you for your interest. This project will welcome collaborators, and
full contribution guidelines are **coming soon**.

Until then:

- **Issues are welcome:** bug reports, rendering problems, and questions
  about the code or the story.
- **Please open an issue before a pull request**, so we can agree on the
  change first. The art follows one artist's style
  (`docs/design/style-bible.md`), and the panels are reviewed by the
  artist, so changes to drawings, panels or the manuscript need that
  conversation first.
- Run `npm test` before you submit anything. A refactor must leave the
  render snapshot unchanged (see the README, Tests).
- Do not trace or copy third-party artwork. Everything is derived from
  the style bible and the artist's own drawings.
